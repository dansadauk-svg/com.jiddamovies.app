JIDDA MOVIES ANDROID 1.0.0

Name: Jidda Movies
Package: com.jiddamovies.app (separate Play Store and Firebase project)
Website: https://jiddamovies.com.ng/
Download notifications: enabled

GITHUB BUILD
1. Upload this project folder's contents to the root of the Jidda Movies GitHub repository.
2. Keep the separate Jidda Movies release signing key safe and private.
3. Add JIDDA_KEYSTORE_BASE64, JIDDA_KEYSTORE_PASSWORD and JIDDA_KEY_PASSWORD as GitHub repository secrets. The signing alias is already fixed to jidda_movies.
4. Firebase is already configured in app/google-services.json. JIDDA_GOOGLE_SERVICES_JSON_BASE64 is only an optional fallback.
5. Open Actions > Build Jidda Movies APK and AAB > Run workflow.
6. Download the APK for testing or AAB for Google Play Console.

APP LINKS
Upload assetlinks.json to:
https://jiddamovies.com.ng/.well-known/assetlinks.json

The certificate fingerprint in assetlinks.json matches the separate Jidda Movies release signing key supplied in the private secrets bundle.
